# 🧠 AI Document Intelligence Platform

An AI-powered document processing system designed for **land/property document verification**.

The system processes documents such as:

* 📄 Encumbrance Certificate (EC)
* 📄 Sale Deed
* 📄 Mutation Document

### Processing Pipeline

```text
Document Upload
       ↓
Preprocessing
       ↓
OCR
       ↓
Text Extraction
       ↓
Document Classification
       ↓
Information Extraction
       ↓
Validation
       ↓
Missing Information Detection
       ↓
Final Verification
```

### Technologies

* Next.js
* React
* TypeScript
* Tailwind CSS
* Python
* PaddleOCR
* AI/ML
* Document Processing

The goal is to reduce manual verification effort and identify missing or inconsistent information automatically.
